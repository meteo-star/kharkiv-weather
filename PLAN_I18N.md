## 1. Цель

Добавить поддержку 6 европейских языков и в **сайт**, и в **бот** так, чтобы:
- Юзер открывает сайт впервые → язык определяется автоматически из `navigator.language` (с fallback на EN если не из списка)
- Юзер запускает `/start` боту → бот определяет язык из `update.message.from.language_code` от Telegram
- При смене языка на сайте → автоматически меняется язык бота через `sub.lang` синхронизацию
- Все push-уведомления и утренняя сводка приходят на родном языке юзера

## 3. Текущее состояние инфраструктуры

### Сайт (готово ~80%)
- `app.js` содержит `TRANSLATIONS = { ru: {...}, uk: {...}, en: {...} }` (~300 ключей в каждом)
- Helper `t(key, params)` уже работает: подставляет `{name}`, `{n}`, etc.
- Switch языка через `state.lang` сохраняется в `localStorage 'kw:settings:v1'.lang`
- Settings UI: segmented control с 3 опциями RU/UK/EN (нужно заменить на dropdown для 9 опций)
- Динамическое обновление: `applyAll()` пересчитывает все `data-i18n` атрибуты

### Бот (нужно построить с нуля)
- Все сообщения **захардкожены** в коде на русском
- В подписке `sub.lang` **уже есть** поле — оно сохраняется при `/start` из `update.message.from.language_code`
- `sub.lang` **не используется** в формировании сообщений (всегда отдаются на русском)
- В `/api/rules-set` поле `lang` **передаётся с сайта**, но в боте не применяется к UI

1. **Создать i18n модуль в боте** (`bot/src/i18n.js` или встроить в `index.js`)
   ```js
   const BOT_TRANSLATIONS = {
     ru: { 'precip.rain.soon': '🌧 <b>Скоро дождь!</b>\n{name}: {mm} мм/ч ...', ... },
     uk: { ... },
     en: { ... },
     de: { ... }, pl: { ... }, cs: { ... }, fr: { ... }, it: { ... }, es: { ... }
   };
   function t(key, lang, params) {
     const lng = BOT_TRANSLATIONS[lang] ? lang : 'en';
     let s = BOT_TRANSLATIONS[lng][key] || BOT_TRANSLATIONS.en[key] || key;
     if (params) for (const [k, v] of Object.entries(params)) s = s.replaceAll(`{${k}}`, v);
     return s;
   }
   ```

## 6. Известные нюансы и подводные камни

1. **Pluralization**: разные языки имеют разные правила.
   - Польский: 1 день / 2-4 dni / 5+ dni
   - Чешский: 1 den / 2-4 dny / 5+ dnů
   - Русский: 1 день / 2-4 дня / 5+ дней
   - English: 1 day / 2+ days
   - **Использовать `Intl.PluralRules`** — даст правильные категории (one/few/many/other) для каждого языка автоматически. Дальше mapping категории → конкретное слово в словаре.

2. **Длина переводов**: немецкие слова длиннее русских/английских.
   - Проверить hero, плитки метрик, плашка nowcast — не ломается ли layout
   - В UI могут потребоваться `text-overflow: ellipsis` + tooltip

3. **Метео-терминология**: AI справляется неплохо, но native review желателен. Особенно для:
   - «sleet» (мокрый снег) — в каждом языке свой нюанс
   - «freezing rain» (ледяной дождь) — различные термины
   - «showers» (ливни) — vs «rain» (продолжительный дождь)

4. **HTML escape в боте**: все шаблоны должны проходить через `esc()` где есть user-input (sub.name). При переводе оставлять `{name}` как есть, escape вызывается отдельно.

5. **Дата-форматирование в боте**: использовать `Intl.DateTimeFormat(lang, ...)` вместо ручного `whenStr`. Это даст «aujourd'hui à 14:00» / «heute um 14:00» / «hoy a las 14:00» автоматически.

6. **Кэш SW**: при добавлении языков bump CACHE_VERSION для PWA force-update.

7. **i18n keys consistency**: ключи на сайте и в боте должны частично совпадать (например `precip.rain.soon`). Можно вынести в общий JSON-файл `i18n/` который читают и сайт, и бот при сборке — но это усложнит инфраструктуру (придется добавить build step). Проще — независимые словари, синхронизировать вручную при изменениях.

8. **Footer источника**: после v1.43.1 каждое сообщение бота имеет `по данным X`. Локализованные варианты:
   - RU: «по данным ECMWF» / «по данным усреднения 8 моделей»
   - EN: «from ECMWF» / «from 8-model average»
   - DE: «von ECMWF» / «aus 8-Modell-Durchschnitt»
   - и т.д.

9. **Команды бота** в Telegram (`/start`, `/help`) можно перевести через **BotFather → Edit Commands**, причём отдельный список на каждый язык. Это не входит в код-задачу, но косметика — стоит сделать.
